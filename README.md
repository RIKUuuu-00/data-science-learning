# データサイエンス方眼帳

AI時代のコンサルタントのための、データサイエンス学習サイトです。未経験者でもイメージできるよう、ほぼすべてのレッスンに動かせる図（アニメーション・スライダー・クリック操作）を入れています。

## 内容

| ページ | 内容 |
| --- | --- |
| `index.html` | ホーム。必要水準（L1／L2／L3）の結論、学習ロードマップ、進捗 |
| `insight.html` | 調査と考察「AI時代、コンサルはデータサイエンスをどこまで知るべきか」。根拠データ、知識の深さマップ、留保、学習プラン、自己診断、出典 |
| `modules/m1.html`〜`m8.html` | 8つの学習モジュール（全43レッスン・確認テスト各4問） |
| `case.html` | ケーススタディ「退会を減らせ」。依頼から運用までの7ステップ |
| `glossary.html` | 用語集（74語、検索・カテゴリ絞り込み） |

モジュール構成：1 全体像をつかむ／2 データを理解する／3 統計で考える／4 機械学習のしくみ／5 生成AIを使いこなす／6 ビジネスで活かす／7 プロジェクトを動かす／8 リスクと信頼

各レッスンには必要水準を表示しています。

- **L1 全員**：全コンサルに必要なデータ・AIリテラシー
- **L2 推進役**：データ・AI案件をリードするトランスレーター（このサイトの到達目標）
- **L3 専門**：モデルや基盤を自ら実装する専門家（協働相手として理解）

## 見かた

ビルドは不要です。`index.html` をブラウザで開けば動きます。ローカルサーバーで開く場合は次のとおりです。

```bash
npx serve .
```

フォントは Google Fonts（Zen Kaku Gothic New、Klee One）から読み込みます。オフラインでも代替フォントで表示されます。学習の進捗・テスト結果・チェックリスト・自己診断は、閲覧者のブラウザ（localStorage）にだけ保存されます。

## デザインの考え方

- **方眼ノート**：コンサルが使う方眼ノートを下地にし、データは「点」で描く
- **書体の使い分け**：データやAIの話は活字（Zen Kaku Gothic New）、人の判断や現場のコツは手書き風（Klee One）
- **色の意味**：藍＝データ・分析、若竹＝モデル・良い結果、山吹＝注目、紅＝リスク
- ライト／ダークの両テーマ、スマートフォン表示、`prefers-reduced-motion` に対応

## ファイル構成

```
assets/
  css/style.css            デザイントークンと全スタイル
  js/icons.js              線画アイコンのスプライト（約100種）
  js/curriculum.js         モジュール・レッスン定義（ナビと進捗の情報源）
  js/core.js               ヘッダー、進捗、目次、クイズ、図の共通部品
  js/viz-foundations.js    ホームとモジュール1〜3の図
  js/viz-ml.js             モジュール4〜5の図
  js/viz-business.js       モジュール6〜8、ケース、考察ページの図
  js/glossary.js           用語集データと検索
```

レッスンを追加・変更するときは、`curriculum.js` の定義と各モジュールHTMLの `data-lesson` をそろえてください。図は `data-widget="名前"` を付けた要素に、各 viz ファイルで `DS.register('名前', fn)` した関数が描画します。
